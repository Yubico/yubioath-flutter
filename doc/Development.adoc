== Building and developing Yubico Authenticator
This document describes how to build and package Yubico Authenticator from
source.

NOTE: Yubico Authenticator 6+ uses a new codebase built using the Flutter
framework. The previous Qt codebase can be found in the `legacy` branch.

=== Requirements
You will need the Flutter SDK with enabled desktop support, see:
https://flutter.dev/desktop

Development has been done using the "Install from git" method of installing the
SDK, from the "stable" channel.

=== Dependencies
This project uses dependencies specified in `pubspec.yaml` and
`helper/crates/helper/Cargo.toml`. The corresponding `pubspec.lock` and
`helper/Cargo.lock` files pin the versions used when building the app.
The Rust helper also uses crates from the sibling `yubikit-rs` checkout.

==== Versioning (important for package maintainers!)
We recommend bundling this application with all its dependencies, using the
versions specified in the lock files. Keep the sibling `yubikit-rs` checkout
at the revision used by the build workflows.

=== Building the Yubico Authenticator Helper
The GUI requires a compiled version of Helper to run, which is built from the
sources in `helper/` in this repository. Install Rust and Cargo and check out
https://github.com/Yubico/yubikey-manager/[yubikit-rs] next to this repository
at the commit pinned in the build workflows. Install `cargo-about` with
`cargo install cargo-about --version 0.9.2 --locked --features cli`.
Build the helper before running `flutter build` or `flutter run`.

==== Windows

For Windows packaging, also build `ykman-svc` from the sibling checkout:

    cargo build --release --manifest-path ..\yubikit-rs\Cargo.toml -p ykman-svc

The local `resources/win/release-win.ps1` packaging script expects the resulting
`ykman-svc.exe` next to the unpacked Windows build artifact.

The MSI and MSIX packages both install `ykman-svc` as an automatic LocalSystem
service. Before installing either package, uninstall any independently installed
`ykman-svc` (for example, one installed by YubiKey Manager CLI); both packages
use the same Windows service name. Installing a package that contains a service
requires administrator privileges. The MSIX requires Windows 10 version 2004
or later and declares the restricted `packagedServices` and
`localSystemServices` capabilities; publishing it to the Microsoft Store may
require approval for these capabilities.

==== macOS

Install the Rust targets `aarch64-apple-darwin` and `x86_64-apple-darwin`
to build the universal helper.

==== Linux (Debian-based distributions)

    $ sudo apt install libu2f-udev pcscd libpcsclite-dev libudev-dev libdbus-1-dev pkg-config libssl-dev

==== Linux (RPM-based distributions)

    # Tested on Fedora 34
    $ sudo dnf install pcsc-lite-devel systemd-devel dbus-devel pkgconf-pkg-config openssl-devel

When prerequisites are installed you build the helper by running `build-helper.sh`
(or `build-helper.bat` on Windows).

NOTE: You will need to re-run the build script if changes have been made to
Helper's code, or if `flutter clean` has been run.

=== Running the app
Before you can build or run the app using the flutter command you need to build
the helper, as described in the previous section!

To start the app, run:

  flutter run -d <os>

where <os> is "windows", "macos", "linux", or an attached Android device name.
use `flutter devices` to list available devices.

You can add the `--release` flag to run a release build instead of debug.

=== Building the app
To build the app without running it, use:

  flutter build <os>

where <os> is "windows", "macos", "linux", or "apk".
Builds of the app will be create under `build/<os>/` for desktop, or
`build/app/` for Android.

=== Running tests
This project uses both unit tests and integration tests.

The unit tests can be run with the command:

  flutter test

These do not require a YubiKey, and are relatively quick to run.

The integration tests are slower but cover more end-to-end functionality. The
require an attached YubiKey to run, and will make modifications to the data
stored on that YubiKey. For instructions on running these tests, see
link:../integration_test/testdoc.adoc[these instructions].
